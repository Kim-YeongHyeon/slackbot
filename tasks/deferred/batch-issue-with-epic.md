# Deferred — 배치 이슈 생성 + 에픽 연결

> **등록일:** 2026-05-14
> **우선순위:** 중간
> **요청자:** 사용자 요청 (Slack에서 복수 스토리 생성 시도 → "이해하지 못했어요" 발생)

## 요구사항

하나의 Slack 메시지로 여러 스토리를 생성하고, 기존 에픽에 연결하는 기능.

### 예시 입력
```
@지라 이슈 추가해줘. 32-bit 최적화 에픽으로 아래 스토리들을 추가하는거야.
기존 32-bit 최적화 에픽이 있다면 그걸 사용해줘.

30-bit prime을 사용하는 IP3 지원
IP3 path에서 narrow/widen 제거
IP2/3에서 evi-ntt 적용, make shared-a 최적화
```

### 기대 동작
1. 에픽 검색: "32-bit 최적화" 에픽이 DB/Jira에 있는지 확인
2. 에픽 존재 시 해당 에픽 사용, 없으면 새로 생성 (또는 사용자에게 확인)
3. 목록의 각 항목을 개별 스토리로 생성
4. 각 스토리의 parent를 에픽으로 설정
5. 결과를 한 번에 보고 (생성된 이슈 키 목록)

## 현재 한계

- 봇은 한 메시지에 하나의 이슈만 생성 가능
- 에픽 검색/연결 API 미구현
- Haiku 분류기가 복합 메시지를 `unknown`으로 분류

## 구현 계획

### 1. 새 intent 추가 (`batch_register`)
- Haiku 프롬프트에 `batch_register` intent 추가
- 트리거: 여러 항목 나열, "에픽으로", "아래 스토리들", 목록 형태 등

### 2. 메시지 파싱
- 에픽 이름 추출
- 개별 스토리 항목 분리 (줄바꿈, 번호, 불릿 등)
- 각 항목에 대해 Sonnet 분류 (제목/SP 추정)

### 3. Jira API 확장
- 에픽 검색: `issueType = Epic AND summary ~ "키워드"` JQL
- 에픽 생성: 기존 createIssue에 issueType=Epic 지원
- 스토리-에픽 연결: `parent` 필드 설정 (Jira next-gen) 또는 Epic Link 커스텀 필드

### 4. 결과 보고
- Block Kit으로 생성된 이슈 목록 표시
- 각 이슈에 Jira 링크 포함

## 고려사항

- 한 번에 생성 가능한 최대 이슈 수 제한 (예: 10개)
- 에픽 검색 결과가 여러 개일 때 선택 UI (버튼)
- 일부 생성 실패 시 부분 성공 처리
